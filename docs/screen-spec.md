# 화면 명세

## 목적

이 문서는 AI 담임 서비스 데모의 첫 구현 기준을 정의합니다.
목표는 완성형 서비스를 설계하는 것이 아니라, 다음 핵심 경험이 화면에서 분명히 보이도록 하는 것입니다.

```text
사전 정의된 커리큘럼을 선택하면,
AI 담임이 오늘 수업을 편성하고,
학생 요구사항과 학습 후 체크 결과에 따라
오늘 수업과 다음 수업을 조율한다.
```

## 화면 설계 원칙

```text
첫 화면은 강의 목록이 아니라 AI 담임의 안내로 시작한다.
현재 상황에 맞는 카드 하나만 화면 중앙에 크게 표시한다.
사용자는 기능 목록을 훑는 것이 아니라 AI 담임의 질문과 제안에 응답한다.
조율 결과는 숨기지 않고 이유와 함께 보여준다.
학습이 밀리거나 이해가 낮아도 비난하지 않고 복구 계획을 제시한다.
개발 및 시현 단계에서는 우측 상단 컨트롤로 모든 카드를 강제로 이동할 수 있다.
```

## 전체 카드 흐름

```text
1. AI 담임 홈
2. 커리큘럼 추천
3. 오늘 수업
4. 학생 요구사항 반영
5. 배정 이유 설명
6. 학습 후 체크
7. 다음 수업 조율 결과
8. 커리큘럼 맵
```

초기 구현에서는 실제 라우팅으로 나누지 않습니다.
단일 React 상태로 현재 단계를 바꾸되, 사용자는 페이지가 단계별로 전환되는 것처럼 느껴야 합니다.

## 공통 레이아웃

```text
상단 우측: 개발용 단계 이동 컨트롤
본문 중앙: 현재 단계의 핵심 카드
카드 상단: AI 담임의 현재 안내
카드 본문: 선택, 입력, 결과 중 현재 필요한 요소
카드 하단: 다음 행동 버튼
보조 영역: 커리큘럼 진행 상태, 조율 이유, 학습 결과 요약
```

## 공통 문구 톤

권장 톤:

```text
오늘은 이 순서로 진행해 보겠습니다.
지금 상태에서는 보강을 먼저 넣는 편이 안전합니다.
오늘 시간이 부족하니 핵심 확인만 남기고 새 진도는 내일로 넘기겠습니다.
진도는 조금 늦어졌지만 아직 복구 가능한 범위입니다.
```

피해야 할 톤:

```text
또 안 했네요.
이러면 실패합니다.
왜 계획을 지키지 않았나요?
```

## 카드 1. AI 담임 홈

### 목적

LLM과 대화하듯이 AI 담임이 오늘 수업을 설명하고, 사용자가 답변하면서 다음 행동으로 이동하게 합니다.

### 공통 구성

```text
제목: 오늘 수업은 이렇게 진행하겠습니다
좌측 말풍선: AI 담임이 오늘 수업 내용과 조율 이유를 설명한다.
우측 말풍선: 사용자의 답변을 표시한다.
입력창 위: 예시 답변 버튼을 표시한다.
하단: 사용자가 직접 답변을 입력할 수 있는 텍스트 입력창을 둔다.
```

### 커리큘럼이 없는 경우

```text
AI 말풍선: 아직 선택된 커리큘럼이 없으므로 학습 흐름을 먼저 추천하겠다고 안내한다.
예시 답변: 커리큘럼 추천받기, 기초부터 안정적으로 가고 싶어요
```

### 커리큘럼이 있는 경우

```text
AI 말풍선: 오늘 목표, 예상 시간, 첫 수업 항목, 조율 이유를 자연어로 설명한다.
보조 정보: 현재 커리큘럼, 현재 단계, 진도율
예시 답변: 오늘 수업 시작할게요, 오늘 시간이 부족해요, 왜 이렇게 배정됐나요?, 전체 커리큘럼 보기
```

## 카드 2. 커리큘럼 추천

### 목적

사용자가 사전 정의된 커리큘럼 중 하나를 선택합니다.
이 선택은 이후 AI 담임이 오늘 수업을 편성하는 기준이 됩니다.

### 표시 항목

```text
커리큘럼 카드 3개
각 카드의 추천 대상
각 카드의 설명
AI 담임 추천 코멘트
```

### 카드 구성

| 카드 | 설명 | 추천 대상 |
| --- | --- | --- |
| 안정형 | 기초 보강과 개념 흐름을 충분히 포함합니다. | 기초가 약하거나 그래프가 불안한 학생 |
| 압축형 | 이미 배운 내용을 빠르게 정리합니다. | 시간이 부족하거나 전체 복습이 필요한 학생 |
| 문제적용형 | 문제 적용과 오답 보강을 중심으로 진행합니다. | 개념은 알지만 문제에서 막히는 학생 |

### 선택 후 상태 변화

```text
selectedCurriculumId 저장
학생 요구사항 기본값으로 초기화
학습 후 체크 입력값 초기화
오늘 수업 카드로 이동
```

## 카드 3. 오늘 수업

### 목적

사용자가 강의 목록을 직접 고르지 않고, AI 담임이 편성한 오늘 수업을 세션처럼 확인합니다.

### 표시 항목

```text
오늘 목표
예상 소요 시간
오늘 수업 항목
각 항목의 종류, 예상 시간, 필수 여부
관련 개념 태그
배치 이유
AI 담임 코멘트
```

### 주요 버튼

```text
수업 완료하고 체크하기
오늘 시간이 부족해요
왜 이렇게 배정됐나요?
전체 커리큘럼 보기
```

## 카드 4. 학생 요구사항 반영

### 목적

학생이 오늘의 시간, 컨디션, 요청 사항을 입력하면 오늘 수업을 조정합니다.

### 빠른 선택

```text
기본 편성
오늘 시간이 부족해요
복습 위주로 하고 싶어요
특정 개념이 헷갈려요
새 강의는 줄이고 싶어요
```

### 표시 항목

```text
선택된 요구사항
수업 조정 요약
AI 담임 조정 이유
```

### 주요 버튼

```text
조정된 수업 보기
조정 이유 보기
```

## 카드 5. 배정 이유 설명

### 목적

AI 담임이 왜 오늘 수업을 그렇게 편성했는지 설명합니다.

### 표시 항목

```text
오늘 수업 배정 이유
규칙 기반 판단 근거 목록
취약 개념 태그
커리큘럼 맵으로 이동하는 버튼
```

## 카드 6. 학습 후 체크

### 목적

오늘 수업 결과를 입력받아 다음 수업 조율의 근거로 사용합니다.

### 입력 항목

| 항목 | 입력 방식 | 값 |
| --- | --- | --- |
| 완료 항목 | 체크박스 | 수업 항목별 완료 여부 |
| 이해도 | 체크박스 선택 | 하나도 모르겠습니다 / 잘 이해가 가지 않습니다 / 조금 이해했습니다 / 이해가 되었습니다 / 설명할 수 있습니다 |
| 집중도 | 체크박스 선택 | 집중이 되지 않았습니다 / 자주 흐트러졌습니다 / 보통이었습니다 / 집중이 잘 되었습니다 / 끝까지 몰입했습니다 |
| 헷갈린 개념 | 체크박스 또는 태그 | 점근선, 평행이동, 정의역, 치역 등 |
| 확인 문제 결과 | 숫자 입력 | 정답 수 / 전체 문항 수 |

### 주요 버튼

```text
다음 수업 조율 보기
오늘 수업 다시 보기
```

### 입력 후 상태 변화

```text
learningCheckSubmission 저장
추천 조율 액션 계산
다음 수업 조율 결과 생성
```

## 카드 7. 다음 수업 조율 결과

### 목적

학습 후 체크 결과가 다음 수업에 실제로 반영되었음을 보여줍니다.

### 표시 항목

```text
조정된 다음 수업 목표
예상 소요 시간
추가된 보강
연기된 진도
AI 담임 코멘트
조율 근거 목록
```

### 주요 버튼

```text
커리큘럼 맵 보기
오늘 수업 다시 보기
```

## 카드 8. 커리큘럼 맵

### 목적

전체 커리큘럼에서 현재 위치, 완료 상태, 취약 개념, 연기된 진도를 보여줍니다.

### 표시 상태

```text
완료
진행 중
예정
보강 필요
연기됨
```

### 주요 버튼

```text
오늘 수업으로 돌아가기
커리큘럼 다시 고르기
```

## 개발용 단계 이동 컨트롤

### 목적

아직 시현 및 개발 단계이므로 정상 플로우를 거치지 않고도 모든 카드를 확인할 수 있게 합니다.

### 구성

```text
우측 상단 고정 영역
단계 선택 드롭다운
이전 버튼
다음 버튼
초기화 버튼
```

### 주의

```text
이 컨트롤은 첫 번째 데모 버전의 시현 편의를 위한 장치입니다.
실제 사용자용 인터페이스에서는 숨기거나 별도 데모 모드로 분리해야 합니다.
```

## 화면별 완료 기준

| 카드 | 완료 기준 |
| --- | --- |
| AI 담임 홈 | LLM 채팅창처럼 AI 말풍선, 사용자 말풍선, 예시 답변, 입력창이 보인다. |
| 커리큘럼 추천 | 3개 커리큘럼을 비교하고 하나를 선택할 수 있다. |
| 오늘 수업 | 오늘 목표, 예상 시간, 수업 구성, 조율 이유가 보인다. |
| 학생 요구사항 반영 | 학생 요청에 따라 오늘 수업 구성과 예상 시간이 바뀐다. |
| 배정 이유 설명 | 수업 배정 근거와 취약 개념이 명확히 보인다. |
| 학습 후 체크 | 이해도, 집중도, 헷갈린 개념, 문제 결과를 입력할 수 있다. |
| 다음 수업 조율 결과 | 보강 추가, 진도 연기, 수업량 조정 이유가 보인다. |
| 커리큘럼 맵 | 현재 위치와 취약 개념 상태가 보인다. |

## 구현에서 제외할 화면

초기 데모에서는 다음 화면을 만들지 않습니다.

```text
로그인
회원가입
결제
관리자 페이지
학부모 리포트
실제 영상 플레이어 상세 화면
문제 자동 생성 화면
정교한 진단 테스트 화면
```
