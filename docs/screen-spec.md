# 화면 명세

## 목적

이 문서는 AI 담임 서비스 데모의 첫 구현 기준을 정의합니다.
목표는 완성형 서비스를 설계하는 것이 아니라, 다음 핵심 경험이 화면에서 분명히 보이도록 하는 것입니다.

```text
사전 정의된 커리큘럼을 선택하면,
AI 담임이 오늘 수업을 편성하고,
학생 요구사항과 학습 후 체크 결과에 따라
오늘 수업과 다음 수업을 조율한다.
```

## 화면 설계 원칙

```text
첫 화면은 강의 목록이 아니라 AI 담임의 안내로 시작한다.
전체 화면은 채팅 앱 구조로 구성한다.
현재 상황에 맞는 카드는 AI 담임 말풍선 안에 첨부한다.
첨부 카드는 독립 페이지가 아니라 채팅 대화에 붙는 작은 인터랙티브 도구처럼 보이게 한다.
사용자는 기능 목록을 훑는 것이 아니라 AI 담임의 질문과 제안에 응답한다.
조율 결과는 숨기지 않고 이유와 함께 보여준다.
학습이 밀리거나 이해가 낮아도 비난하지 않고 복구 계획을 제시한다.
개발 및 시현 단계에서는 우측 상단 컨트롤로 AI 답변에 첨부될 카드를 강제로 바꿀 수 있다.
```

## 전체 채팅 흐름

```text
1. AI 담임 홈
2. 커리큘럼 추천
3. 오늘 수업
4. 학생 요청 입력과 AI 담임의 내부 조율
5. 조정 수업 제안과 확인
6. 배정 이유 설명
7. 학습 후 체크
8. 다음 수업 조율 결과
9. 커리큘럼 맵
```

초기 구현에서는 실제 라우팅으로 나누지 않습니다.
단일 React 상태로 현재 대화 단계를 바꾸되, 사용자는 AI 담임과 대화하면서 필요한 카드가 답변에 첨부되는 것처럼 느껴야 합니다.

## 공통 레이아웃

```text
상단 우측: 개발용 단계 이동 컨트롤
상단: 채팅 앱 제목
본문: AI 담임과 사용자 말풍선
AI 말풍선 내부: 현재 단계의 핵심 첨부 카드
하단: 예시 답변 버튼과 텍스트 입력창
첨부 카드 내부: 선택, 입력, 결과 중 현재 필요한 요소를 조밀하게 표시
채팅 기록: 버튼 클릭과 텍스트 입력으로 만든 사용자 말풍선과 AI 응답을 누적 표시
AI 응답 대기: 사용자 입력 후 0.5초 동안 준비 중 점 애니메이션 표시
```

## 공통 문구 톤

권장 톤:

```text
오늘은 이 순서로 진행해 보겠습니다.
지금 상태에서는 보강을 먼저 넣는 편이 안전합니다.
오늘 시간이 부족하니 핵심 확인만 남기고 새 진도는 내일로 넘기겠습니다.
진도는 조금 늦어졌지만 아직 복구 가능한 범위입니다.
```

피해야 할 톤:

```text
또 안 했네요.
이러면 실패합니다.
왜 계획을 지키지 않았나요?
```

## 카드 1. AI 담임 홈

### 목적

채팅 앱의 첫 대화로 AI 담임이 오늘 수업을 설명하고, 필요한 카드를 답변 안에 첨부합니다.
카드는 전체 페이지처럼 보이지 않고, 메신저 안에 붙는 요약 카드와 선택 도구처럼 보여야 합니다.

### 공통 구성

```text
제목: 오늘 수업은 이렇게 진행하겠습니다
좌측 말풍선: AI 담임이 오늘 수업 내용과 조율 이유를 설명한다.
우측 말풍선: 사용자의 답변을 표시한다.
말풍선 안의 첨부 카드: 홈 요약, 커리큘럼 추천, 오늘 수업 등 현재 단계 도구
입력창 위: 예시 답변 버튼을 표시한다.
하단: 사용자가 직접 답변을 입력할 수 있는 텍스트 입력창을 둔다.
답변 지연: 사용자 말풍선이 추가된 뒤 0.5초 동안 AI 담임이 답변을 준비 중인 상태를 표시한다.
```

### 커리큘럼이 없는 경우

```text
AI 말풍선: 아직 선택된 커리큘럼이 없으므로 학습 흐름을 먼저 추천하겠다고 안내하고 홈 요약 카드를 첨부한다.
예시 답변: 커리큘럼 추천받기, 기초부터 안정적으로 가고 싶어요
```

### 커리큘럼이 있는 경우

```text
AI 말풍선: 오늘 목표, 예상 시간, 첫 수업 항목, 조율 이유를 자연어로 설명하고 읽기 전용 오늘의 학습 안내 카드를 첨부한다.
보조 정보: 현재 커리큘럼, 현재 단계, 진도율
예시 답변: 오늘 수업 시작할게요, 오늘 시간이 부족해요, 왜 이렇게 배정됐나요?, 전체 커리큘럼 보기
```

## 카드 2. 커리큘럼 추천

### 목적

사용자가 사전 정의된 커리큘럼 중 하나를 선택합니다.
이 선택은 이후 AI 담임이 오늘 수업을 편성하는 기준이 됩니다.

### 표시 항목

```text
커리큘럼 카드 3개
각 카드의 추천 대상
각 카드의 설명
AI 담임 추천 코멘트
```

### 카드 구성

| 카드 | 설명 | 추천 대상 |
| --- | --- | --- |
| 안정형 | 기초 보강과 개념 흐름을 충분히 포함합니다. | 기초가 약하거나 그래프가 불안한 학생 |
| 압축형 | 이미 배운 내용을 빠르게 정리합니다. | 시간이 부족하거나 전체 복습이 필요한 학생 |
| 문제적용형 | 문제 적용과 오답 보강을 중심으로 진행합니다. | 개념은 알지만 문제에서 막히는 학생 |

### 선택 후 상태 변화

```text
selectedCurriculumId 저장
학생 요구사항 기본값으로 초기화
학습 후 체크 입력값 초기화
AI 담임이 내부에서 오늘 수업을 편성하고, 말풍선으로 편성안을 제안
```

## 내부 도구 3. 오늘 수업 편성

### 목적

AI 담임이 선택된 커리큘럼과 학생 상태를 바탕으로 오늘 수업을 편성합니다.
이 도구는 사용자가 직접 조작하거나 카드 형태로 확인하지 않습니다.

### 표시 항목

```text
오늘 목표
예상 소요 시간
오늘 수업 항목과 순서
항목별 배치 이유
AI 담임 제안 문장
```

### 사용자에게 보이는 결과

```text
AI 담임 말풍선에 편성의 핵심 내용과 확인 질문, 읽기 전용 오늘의 학습 안내 카드가 표시된다.
사용자는 하단 예시 답변 또는 입력창으로만 동의하거나 수정 의견을 보낸다.
오늘의 학습 안내 카드는 목표, 시간, 항목을 구조적으로 보여 주되 버튼, 입력, 선택 기능을 제공하지 않는다.
강의 항목 제목은 더미 강의 세션으로 이동하는 링크로만 제공하며, 팝업이나 외부 사이트로 이동하지 않는다.
강의 세션의 완료 동작 뒤에는 AI 담임 채팅으로 돌아가 이해도와 집중도만 선택하는 강의별 간단 체크를 이어 간다.
기본 안정형 데모는 점근선과 정의역, 평행이동, 로그방정식 개념 미리 보기의 짧은 강의 3편으로 구성한다.
오늘 수업의 편성 및 조정 도구 자체는 노출하지 않는다.
```

## 단계 4. 학생 요청 입력과 AI 담임의 내부 조율

### 목적

학생은 채팅으로 오늘의 시간, 컨디션, 요청 사항을 말합니다.
AI 담임은 내부 조율 도구를 사용해 오늘 수업을 조정합니다.

### 사용자 입력 예시

```text
오늘 시간이 부족해요
복습 위주로 하고 싶어요
특정 개념이 헷갈려요
새 강의는 줄이고 싶어요
```

### 화면 처리 원칙

```text
사용자 요청은 하단 예시 답변 또는 입력창에서만 보낸다.
요구사항 반영 기능 자체는 별도 카드나 직접 조작 버튼으로 노출하지 않는다.
시간 제한과 복습 우선처럼 복합적인 요청도 하나의 내부 조율 조건으로 함께 반영한다.
```

## 단계 5. 조정 수업 제안과 확인

### 목적

AI 담임이 내부 조율 결과를 바탕으로 가장 적절한 편성안 하나를 먼저 제안하고,
사용자에게 자연어로 의견을 묻습니다.

### 표시 항목

```text
조정된 오늘 수업의 목표, 시간, 항목 요약이 담긴 AI 담임 말풍선과 읽기 전용 오늘의 학습 안내 카드
기존 계획에서 달라진 항목
조정 이유와 목표일 영향
이 편성으로 진행할지 묻는 AI 담임 메시지
```

### 완료 기준

```text
사용자가 수업 조정 도구를 직접 보지 않고도,
AI 담임이 제안한 편성안과 그 이유를 이해하고 의견을 답할 수 있다.
```

## 카드 6. 배정 이유 설명

### 목적

AI 담임이 왜 오늘 수업을 그렇게 편성했는지 설명합니다.

### 표시 항목

```text
오늘 수업 배정 이유
규칙 기반 판단 근거 목록
취약 개념 태그
커리큘럼 맵으로 이동하는 버튼
```

## 카드 7. 강의별 간단 체크

### 목적

강의 종료 직후 이해도와 집중도만 받아 다음 수업 조율의 내부 근거로 사용합니다.
체크 UI는 강의 화면 중앙의 모달로 띄워 강의 정보 패널과 분리합니다.

### 입력 항목

| 항목 | 입력 방식 | 값 |
| --- | --- | --- |
| 이해도 | 체크박스 단일 선택 | 이해가 어려웠어요 / 대체로 이해했어요 / 잘 이해했어요 |
| 집중도 | 체크박스 단일 선택 | 집중이 어려웠어요 / 보통이었어요 / 집중했어요 |

### 주요 버튼

```text
AI 담임에게 전달하기
```

### 입력 후 상태 변화

```text
강의별 이해도·집중도와 개념 태그 저장
내부 다음 수업 조율 신호 계산
읽기 전용 오늘의 학습 진행 보고 생성
```

## 카드 8. 오늘의 학습 진행 보고

### 목적

강의별 응답이 반영되었음을 짧게 보고하고, 다음 수업 상세 조율은 AI 담임 내부 도구로 유지합니다.

### 표시 항목

```text
완료한 강의
해당 강의의 이해도와 집중도
AI 담임의 짧은 반영 안내
아직 보지 않은 다음 추천 강의
```

### 주요 버튼

```text
다음 추천 강의 자동 이어 보기
5초 자동 재생 카운트와 자동 재생 취소
모든 강의 완료 후 채팅으로 부족한 부분 알려 주기
모든 강의 완료 후 오늘 학습 안내 보기
```

## 카드 9. 커리큘럼 맵

### 목적

전체 커리큘럼에서 현재 위치, 완료 상태, 취약 개념, 연기된 진도를 보여줍니다.

### 표시 상태

```text
완료
진행 중
예정
보강 필요
연기됨
```

### 주요 버튼

```text
오늘 수업으로 돌아가기
커리큘럼 다시 고르기
```

## 개발용 단계 이동 컨트롤

### 목적

아직 시현 및 개발 단계이므로 정상 플로우를 거치지 않고도 모든 카드를 확인할 수 있게 합니다.

### 구성

```text
우측 상단 고정 영역
단계 선택 드롭다운
이전 버튼
다음 버튼
초기화 버튼
```

### 주의

```text
이 컨트롤은 첫 번째 데모 버전의 시현 편의를 위한 장치입니다.
실제 사용자용 인터페이스에서는 숨기거나 별도 데모 모드로 분리해야 합니다.
```

## 화면별 완료 기준

| 카드 | 완료 기준 |
| --- | --- |
| AI 담임 홈 | 채팅 앱 안에서 AI 말풍선, 사용자 말풍선, 첨부 카드, 예시 답변, 입력창이 보인다. |
| 커리큘럼 추천 | 3개 커리큘럼을 비교하고 하나를 선택할 수 있다. |
| 오늘 수업 | 오늘 목표, 예상 시간, 수업 구성, 조율 이유가 보인다. |
| 학생 요청 입력과 AI 담임의 내부 조율 | 채팅 요청을 바탕으로 AI 담임이 조정안을 생성한다. |
| 조정 수업 제안과 확인 | AI 담임이 편성안을 먼저 제안하고 사용자의 의견을 묻는다. |
| 배정 이유 설명 | 수업 배정 근거와 취약 개념이 명확히 보인다. |
| 강의별 간단 체크 | 강의 직후 이해도와 집중도만 선택할 수 있다. |
| 오늘의 학습 진행 보고 | 완료 강의와 간단 체크 결과, 내부 반영 안내가 읽기 전용으로 보인다. |
| 커리큘럼 맵 | 현재 위치와 취약 개념 상태가 보인다. |

## 구현에서 제외할 화면

초기 데모에서는 다음 화면을 만들지 않습니다.

```text
로그인
회원가입
결제
관리자 페이지
학부모 리포트
실제 영상 플레이어 상세 화면
문제 자동 생성 화면
정교한 진단 테스트 화면
```
