# 화면 명세

## 목적

이 문서는 AI 담임 서비스 데모의 첫 구현 기준을 정의합니다.
목표는 완성형 서비스를 설계하는 것이 아니라, 다음 핵심 경험이 화면에서 분명히 보이도록 하는 것입니다.

```text
사전 정의된 커리큘럼을 선택하면,
AI 담임이 오늘 수업을 편성하고,
학생 요구사항과 학습 후 체크 결과에 따라
오늘 수업과 다음 수업을 조율한다.
```

## 화면 설계 원칙

```text
첫 화면은 강의 목록이 아니라 AI 담임이 편성한 오늘 수업을 보여준다.
사용자는 AI 담임의 제안을 따를 수 있지만, 오늘 상황을 말해 조정할 수 있다.
조율 결과는 숨기지 않고 이유와 함께 보여준다.
학습이 밀리거나 이해가 낮아도 비난하지 않고 복구 계획을 제시한다.
초기 데모에서는 모든 화면을 단일 페이지 흐름으로 구현해도 된다.
```

## 전체 화면 흐름

```text
1. 커리큘럼 선택
2. AI 담임 홈
3. 오늘 수업 조정
4. 오늘 수업 진행
5. 학습 후 체크
6. 다음 수업 조율 결과
7. 커리큘럼 맵
```

초기 구현에서는 화면 전환을 실제 라우팅으로 나누지 않아도 됩니다.
단일 페이지 안에서 현재 단계 상태를 바꾸는 방식으로 충분합니다.

## 공통 레이아웃

### 화면 공통 구성

```text
상단: 서비스 이름, 현재 데모 범위, 진행 단계
본문: 현재 화면의 핵심 행동
하단 또는 우측: AI 담임 코멘트, 다음 행동 버튼
보조 영역: 커리큘럼 진행 상태 또는 조율 이유
```

### 공통 문구 톤

권장 톤:

```text
오늘은 이 순서로 진행해 보겠습니다.
지금 상태에서는 보강을 먼저 넣는 편이 안전합니다.
오늘 시간이 부족하니 핵심 확인만 남기고 새 진도는 내일로 넘기겠습니다.
진도는 조금 늦어졌지만 아직 복구 가능한 범위입니다.
```

피해야 할 톤:

```text
또 안 했네요.
이러면 실패합니다.
왜 계획을 지키지 않았나요?
```

## 화면 1. 커리큘럼 선택

### 목적

사용자가 사전 정의된 커리큘럼 중 하나를 선택합니다.
이 선택은 이후 AI 담임이 오늘 수업을 편성하는 기준이 됩니다.

### 주요 사용자 행동

```text
커리큘럼 카드 비교
추천 대상 확인
학습 흐름 확인
커리큘럼 선택
```

### 표시 항목

```text
화면 제목: 로그함수 학습 흐름을 선택해 주세요
보조 설명: AI 담임이 선택한 흐름을 기준으로 오늘 수업과 다음 진도를 조율합니다.
커리큘럼 카드 3개
각 카드의 추천 대상
각 카드의 단계 목록
선택 버튼
AI 담임 추천 코멘트
```

### 카드 구성

| 카드 | 설명 | 추천 대상 |
| --- | --- | --- |
| 안정형 | 기초 보강과 개념 흐름을 충분히 포함합니다. | 기초가 약하거나 그래프가 불안한 학생 |
| 압축형 | 이미 배운 내용을 빠르게 정리합니다. | 시간이 부족하거나 전체 복습이 필요한 학생 |
| 문제적용형 | 문제 적용과 오답 보강을 중심으로 진행합니다. | 개념은 알지만 문제에서 막히는 학생 |

### 주요 버튼

```text
이 커리큘럼으로 시작
AI 담임 추천 보기
```

### 선택 후 상태 변화

```text
selectedCurriculumId 저장
currentStepId 초기화
오늘 수업 생성
AI 담임 홈으로 이동
```

## 화면 2. AI 담임 홈

### 목적

사용자가 앱에 들어왔을 때 강의 목록이 아니라, AI 담임이 편성한 오늘 수업을 먼저 확인하게 합니다.

### 주요 사용자 행동

```text
오늘 목표 확인
오늘 수업 구성 확인
AI 담임의 조율 이유 확인
오늘 수업 시작
시간 부족 또는 복습 요청
전체 커리큘럼 확인
```

### 표시 항목

```text
오늘 목표
예상 소요 시간
오늘 수업 항목
현재 커리큘럼 단계
취약 개념
AI 담임 코멘트
주요 행동 버튼
```

### 오늘 수업 카드 구성

```text
수업 제목
수업 종류: 강의 / 보강 / 문제 / 확인
예상 시간
필수 여부
관련 개념 태그
배치 이유
```

### 주요 버튼

```text
오늘 수업 시작
오늘 시간이 부족해요
복습 위주로 바꿔 주세요
왜 이렇게 배정됐나요?
전체 커리큘럼 보기
```

### AI 담임 코멘트 예시

```text
오늘은 로그함수 그래프의 점근선과 평행이동을 먼저 정리하겠습니다.
이전 체크에서 평행이동 실수가 있어 새 진도 전에 짧은 보강을 앞에 배치했습니다.
```

## 화면 3. 오늘 수업 조정

### 목적

학생이 오늘의 시간, 컨디션, 요청 사항을 입력하면 오늘 수업을 조정합니다.

### 진입 방식

```text
AI 담임 홈에서 오늘 시간이 부족해요 선택
AI 담임 홈에서 복습 위주로 바꿔 주세요 선택
학생 요청 입력 영역에 직접 입력
```

### 입력 방식

초기 데모에서는 자유 입력과 빠른 선택 버튼을 함께 둡니다.

빠른 선택:

```text
20분만 가능해요
복습 위주로 하고 싶어요
새 강의는 줄이고 싶어요
그래프가 헷갈려요
문제만 풀고 싶어요
```

자유 입력 예시:

```text
오늘 시간이 20분밖에 없어요.
로그함수 그래프가 아직 헷갈려요.
오늘은 새 강의보다 복습을 하고 싶어요.
```

### 표시 항목

```text
기존 오늘 수업
조정 후 오늘 수업
줄어든 항목
내일로 이동한 항목
AI 담임 조정 이유
```

### 조정 결과 예시

```text
기존: 42분 수업
조정 후: 20분 핵심 수업

남긴 항목:
1. 점근선 보강 8분
2. 그래프 확인 문제 2개

내일로 이동:
로그방정식 개념 강의 20분
```

## 화면 4. 오늘 수업 진행

### 목적

오늘 수업을 하나의 세션처럼 보여줍니다.
실제 영상 스트리밍은 구현하지 않고, 데모용 수업 항목 진행 상태만 보여줍니다.

### 표시 항목

```text
현재 진행 중인 수업 항목
전체 수업 항목 목록
완료 처리 버튼
건너뛰기 또는 나중에 하기 버튼
예상 남은 시간
AI 담임 짧은 안내
```

### 수업 항목 상태

```text
예정
진행 중
완료
건너뜀
내일로 이동
```

### 주의

초기 데모에서는 실제 영상 플레이어를 만들지 않습니다.
수업 항목은 카드 기반의 진행 흐름으로 충분합니다.

## 화면 5. 학습 후 체크

### 목적

오늘 수업 결과를 입력받아 다음 수업 조율의 근거로 사용합니다.

### 입력 항목

```text
완료 여부
이해도
집중도
헷갈린 개념
확인 문제 결과
```

### 상세 입력

| 항목 | 입력 방식 | 값 |
| --- | --- | --- |
| 완료 여부 | 선택 버튼 | 완료 / 일부 완료 / 미완료 |
| 이해도 | 선택 버튼 | 쉬움 / 보통 / 어려움 |
| 집중도 | 선택 버튼 | 높음 / 보통 / 낮음 |
| 헷갈린 개념 | 체크박스 또는 태그 | 점근선, 평행이동, 정의역, 치역 등 |
| 확인 문제 결과 | 숫자 입력 또는 스테퍼 | 정답 수 / 전체 문항 수 |

### 주요 버튼

```text
결과 반영하기
오늘 수업으로 돌아가기
```

### 입력 후 상태 변화

```text
lastLearningCheck 저장
weakConcepts 갱신
completedStepIds 갱신
delayedStepIds 갱신
다음 수업 조율 결과 생성
```

## 화면 6. 다음 수업 조율 결과

### 목적

학습 후 체크 결과가 다음 수업에 실제로 반영되었음을 보여줍니다.

### 표시 항목

```text
오늘 학습 결과 요약
기존 다음 수업
조정된 다음 수업
추가된 보강
연기된 진도
복구 계획
AI 담임 코멘트
```

### 결과 카드 구성

```text
변경 유형: 보강 추가 / 수업량 축소 / 진도 연기 / 그대로 진행
변경 전
변경 후
근거
학생에게 필요한 다음 행동
```

### AI 담임 코멘트 예시

```text
오늘 확인 문제에서 평행이동 실수가 반복되었습니다.
내일 수업 앞에 8분 보강을 추가하고, 로그방정식 강의는 25분으로 줄이겠습니다.
진도는 조금 늦어졌지만 아직 복구 가능한 범위입니다.
```

### 주요 버튼

```text
내일 수업 미리 보기
커리큘럼 맵 보기
오늘 결과 다시 수정
```

## 화면 7. 커리큘럼 맵

### 목적

전체 커리큘럼에서 현재 위치, 완료 상태, 취약 개념, 연기된 진도를 보여줍니다.

### 표시 항목

```text
선택한 커리큘럼 이름
전체 단계 목록
각 단계 상태
취약 개념 태그
보강 필요 표시
다음 예정 수업
```

### 단계 상태

```text
완료
진행 중
예정
보강 필요
연기됨
```

### 주의

커리큘럼 맵은 보조 화면입니다.
초기 데모의 중심은 여전히 AI 담임 홈과 다음 수업 조율 결과입니다.

## 초기 구현 우선순위

정적 화면 구현 시 우선순위는 다음과 같습니다.

```text
1. AI 담임 홈
2. 커리큘럼 선택
3. 학습 후 체크
4. 다음 수업 조율 결과
5. 커리큘럼 맵
6. 오늘 수업 진행
7. 오늘 수업 조정
```

오늘 수업 조정은 핵심 기능이지만, 화면 구현만 놓고 보면 AI 담임 홈과 조율 결과가 먼저 보이는 편이 데모 이해에 유리합니다.

## 화면별 완료 기준

| 화면 | 완료 기준 |
| --- | --- |
| 커리큘럼 선택 | 3개 커리큘럼을 비교하고 하나를 선택할 수 있다. |
| AI 담임 홈 | 오늘 목표, 예상 시간, 수업 구성, 조율 이유가 보인다. |
| 오늘 수업 조정 | 학생 요청에 따라 변경 전후 수업 구성이 비교된다. |
| 오늘 수업 진행 | 수업 항목을 세션처럼 진행 상태로 볼 수 있다. |
| 학습 후 체크 | 이해도, 집중도, 헷갈린 개념, 문제 결과를 입력할 수 있다. |
| 다음 수업 조율 결과 | 보강 추가, 진도 연기, 수업량 조정 이유가 보인다. |
| 커리큘럼 맵 | 현재 위치와 취약 개념 상태가 보인다. |

## 구현에서 제외할 화면

초기 데모에서는 다음 화면을 만들지 않습니다.

```text
로그인
회원가입
결제
관리자 페이지
학부모 리포트
실제 영상 플레이어 상세 화면
문제 자동 생성 화면
정교한 진단 테스트 화면
```
