# 데모 화면 흐름

## 목표 경험

사용자는 강의 목록이나 여러 기능 카드를 직접 찾아다니는 것이 아니라, AI 담임과 대화하듯 현재 필요한 카드만 하나씩 확인해야 합니다.

데모의 핵심 흐름은 다음 한 문장으로 정리합니다.

```text
커리큘럼을 선택하면 AI 담임이 오늘 수업을 만들고,
학생 요구사항과 학습 후 체크 결과에 따라 오늘 수업과 다음 수업을 조율한다.
```

## 인터랙션 방식

첫 번째 데모 버전은 스크롤형 대시보드가 아니라 **스텝형 인터랙션 플로우**로 구성합니다.

```text
현재 상황에 맞는 카드 하나만 화면 중앙에 크게 표시한다.
사용자의 선택 또는 입력이 끝나면 다음 카드로 이동한다.
각 카드는 AI 담임이 사용하는 도구처럼 동작한다.
사용자는 기능 목록을 따라가는 것이 아니라 AI 담임의 안내를 따라간다.
```

개발 및 시현 단계에서는 우측 상단에 작은 개발용 단계 이동 컨트롤을 둡니다.

```text
드롭다운으로 모든 카드에 강제 이동할 수 있다.
이전/다음 버튼으로 흐름을 앞뒤로 넘길 수 있다.
초기화 버튼으로 커리큘럼 선택 전 상태를 다시 확인할 수 있다.
```

## 전체 흐름

```text
1. AI 담임 홈
2. 커리큘럼 추천
3. 오늘 수업
4. 학생 요구사항 반영
5. 배정 이유 설명
6. 학습 후 체크
7. 다음 수업 조율 결과
8. 커리큘럼 맵
```

## 카드 1. AI 담임 홈

목적:

```text
LLM과 대화하듯이 AI 담임이 오늘 수업을 설명하고 다음 행동을 안내한다.
```

초기 상태:

```text
커리큘럼이 정의되어 있지 않으면 AI 말풍선으로 커리큘럼 추천을 안내한다.
사용자는 예시 답변 또는 입력창으로 커리큘럼 추천을 요청한다.
```

커리큘럼 선택 후:

```text
AI 말풍선이 오늘 수업 목표, 예상 시간, 첫 수업 항목, 조율 이유를 설명한다.
사용자는 오른쪽 말풍선으로 답변한다.
입력창 위에는 오늘 수업 시작, 시간 부족, 배정 이유, 커리큘럼 맵 보기 예시 답변을 제공한다.
```

## 카드 2. 커리큘럼 추천

목적:

```text
사용자가 사전 정의된 커리큘럼 중 하나를 선택한다.
```

표시 요소:

```text
커리큘럼 카드 3개
각 커리큘럼의 추천 대상
예상 학습 흐름
AI 담임의 짧은 추천 코멘트
```

주의:

```text
초기 데모에서는 커리큘럼 자동 생성을 제공하지 않는다.
커리큘럼을 선택하면 바로 오늘 수업 카드로 이동한다.
```

## 카드 3. 오늘 수업

목적:

```text
AI 담임이 편성한 오늘 수업을 하나의 세션처럼 보여준다.
```

표시 요소:

```text
오늘 목표
예상 소요 시간
오늘 수업 구성
각 항목의 배치 이유
AI 담임 코멘트
```

주요 선택지:

```text
수업 완료하고 체크하기
오늘 시간이 부족해요
왜 이렇게 배정됐나요?
전체 커리큘럼 보기
```

## 카드 4. 학생 요구사항 반영

목적:

```text
학생의 현재 상황을 반영해 오늘 수업을 조정한다.
```

빠른 선택:

```text
기본 편성
오늘 시간이 부족해요
복습 위주로 하고 싶어요
특정 개념이 헷갈려요
새 강의는 줄이고 싶어요
```

처리 방식:

```text
요구사항 해석은 mock AI 또는 LLM 연결 지점으로 분리한다.
수업 조정 자체는 규칙 기반 엔진이 처리한다.
```

## 카드 5. 배정 이유 설명

목적:

```text
AI 담임이 왜 오늘 수업을 그렇게 편성했는지 설명한다.
```

표시 요소:

```text
오늘 수업 배정 이유
취약 개념 반영 이유
수업 시간 제한 또는 학생 요구사항 반영 결과
보강 필요 개념
```

## 카드 6. 학습 후 체크

목적:

```text
오늘 학습 결과를 입력받아 다음 수업 조율의 근거로 사용한다.
```

입력 항목:

```text
완료 항목
이해도
집중도
헷갈린 개념
확인 문제 결과
```

## 카드 7. 다음 수업 조율 결과

목적:

```text
학습 후 체크 결과가 다음 수업에 실제로 반영되었음을 보여준다.
```

표시 요소:

```text
조정된 다음 수업
추가된 보강
연기된 진도
조정 이유
AI 담임 코멘트
```

권장 문구 예시:

```text
오늘 확인 문제에서 평행이동 실수가 반복되었습니다.
내일 수업 앞에 8분 보강을 추가하고, 로그방정식 강의는 25분으로 줄이겠습니다.
진도는 조금 늦어졌지만 아직 복구 가능한 범위입니다.
```

## 카드 8. 커리큘럼 맵

목적:

```text
전체 커리큘럼 중 현재 위치와 취약 개념 상태를 보여준다.
```

표시 상태:

```text
완료
진행 중
예정
보강 필요
연기됨
```

주의:

```text
커리큘럼 맵은 전체 서비스의 복잡한 학습 관리 화면이 아니라,
AI 담임이 진도를 조율하고 있다는 사실을 보조적으로 보여주는 카드이다.
```

## 데모 성공 기준과 카드 연결

| 성공 기준 | 연결 카드 |
| --- | --- |
| 사전 정의 커리큘럼 선택 | 커리큘럼 추천 |
| 선택된 커리큘럼에 따른 오늘 수업 생성 | 오늘 수업 |
| 수업 세션처럼 보이는 오늘 수업 | 오늘 수업 |
| 학생 요구사항에 따른 조정 | 학생 요구사항 반영 |
| 학습 후 체크 결과 반영 | 학습 후 체크, 다음 수업 조율 결과 |
| 조율 결과 명확 표시 | 다음 수업 조율 결과 |
| AI 담임의 조율 이유 설명 | 배정 이유 설명, 다음 수업 조율 결과 |
| 커리큘럼 맵에서 진도와 취약 개념 표시 | 커리큘럼 맵 |
