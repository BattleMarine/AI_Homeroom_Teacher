# 데모 화면 흐름

## 목표 경험

사용자는 강의 목록을 직접 고르는 것이 아니라, AI 담임이 오늘 해야 할 수업을 먼저 편성해 주는 경험을 봐야 합니다.

데모의 핵심 흐름은 다음 한 문장으로 정리합니다.

```text
커리큘럼을 선택하면 AI 담임이 오늘 수업을 만들고,
학생 요구사항과 학습 후 체크 결과에 따라 오늘 수업과 다음 수업을 조율한다.
```

## 전체 흐름

```text
1. 커리큘럼 선택
2. AI 담임 홈
3. 오늘 수업 확인
4. 학생 요구사항 반영
5. 오늘 수업 조정
6. 학습 진행
7. 학습 후 체크
8. 다음 수업 조율 결과 확인
9. 커리큘럼 맵 확인
```

## 화면 1. 커리큘럼 선택

목적:

```text
사용자가 사전 정의된 커리큘럼 중 하나를 선택한다.
```

표시 요소:

```text
커리큘럼 카드 3개
각 커리큘럼의 추천 대상
예상 학습 흐름
선택 버튼
AI 담임의 짧은 추천 코멘트
```

초기 커리큘럼:

```text
안정형
압축형
문제적용형
```

주의:

```text
초기 데모에서는 커리큘럼 자동 생성을 제공하지 않는다.
```

## 화면 2. AI 담임 홈

목적:

```text
첫 화면을 강의 목록이 아니라 오늘 수업 세션 중심으로 보여준다.
```

표시 요소:

```text
오늘 목표
예상 소요 시간
오늘 수업 구성
AI 담임 코멘트
현재 진도 상태
취약 개념 알림
```

주요 선택지:

```text
오늘 수업 시작
오늘 시간이 부족해요
왜 이렇게 배정됐나요?
전체 커리큘럼 보기
```

권장 문구 예시:

```text
오늘은 그래프 해석을 먼저 안정시키고, 이어서 로그방정식 개념으로 넘어가겠습니다.
어제 확인 문제에서 평행이동 실수가 있어 짧은 보강을 앞에 배치했습니다.
```

## 화면 3. 학생 요구사항 반영

목적:

```text
학생의 현재 상황을 반영해 오늘 수업을 조정한다.
```

입력 예시:

```text
오늘 시간이 20분밖에 없어요.
오늘은 새 강의보다 복습을 하고 싶어요.
로그함수 그래프가 아직 헷갈려요.
```

처리 방식:

```text
요구사항 해석은 mock AI 또는 LLM 연결 지점으로 분리한다.
수업 조정 자체는 규칙 기반 엔진이 처리한다.
```

조정 결과 예시:

```text
전체 수업 42분
→ 핵심 보강 8분 + 확인 문제 2개로 축소

내일 수업 앞에 로그방정식 개념 강의를 이어서 배치
```

## 화면 4. 학습 후 체크

목적:

```text
오늘 학습 결과를 입력받아 다음 수업 조율의 근거로 사용한다.
```

입력 항목:

```text
완료 여부
이해도
집중도
헷갈린 개념
확인 문제 결과
```

입력 예시:

```text
완료 여부: 일부 완료
이해도: 어려움
집중도: 낮음
헷갈린 개념: 점근선, 평행이동
확인 문제: 3문항 중 1문항 정답
```

## 화면 5. 다음 수업 조율 결과

목적:

```text
학습 후 체크 결과가 다음 수업에 실제로 반영되었음을 보여준다.
```

표시 요소:

```text
기존 다음 수업
조정된 다음 수업
추가된 보강
연기된 진도
조정 이유
AI 담임 코멘트
```

권장 문구 예시:

```text
오늘 확인 문제에서 평행이동 실수가 반복되었습니다.
내일 수업 앞에 8분 보강을 추가하고, 로그방정식 개념 강의는 25분으로 줄이겠습니다.
진도는 조금 늦어졌지만 아직 복구 가능한 범위입니다.
```

## 화면 6. 커리큘럼 맵

목적:

```text
전체 커리큘럼 중 현재 위치와 취약 개념 상태를 보여준다.
```

표시 상태:

```text
완료
진행 중
예정
보강 필요
연기됨
```

주의:

```text
커리큘럼 맵은 전체 서비스의 복잡한 학습 관리 화면이 아니라,
AI 담임이 진도를 조율하고 있다는 사실을 보조적으로 보여주는 화면이다.
```

## 데모 성공 기준과 화면 연결

| 성공 기준 | 연결 화면 |
| --- | --- |
| 사전 정의 커리큘럼 선택 | 커리큘럼 선택 |
| 선택된 커리큘럼에 따른 오늘 수업 생성 | AI 담임 홈 |
| 수업 세션처럼 보이는 오늘 수업 | AI 담임 홈, 오늘 수업 확인 |
| 학생 요구사항에 따른 조정 | 학생 요구사항 반영 |
| 학습 후 체크 결과 반영 | 학습 후 체크, 다음 수업 조율 결과 |
| 조율 결과 명확 표시 | 다음 수업 조율 결과 |
| AI 담임의 조율 이유 설명 | AI 담임 홈, 다음 수업 조율 결과 |
| 커리큘럼 맵에서 진도와 취약 개념 표시 | 커리큘럼 맵 |
